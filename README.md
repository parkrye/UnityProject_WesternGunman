# Western Gunman

서부 마을의 보안관이 되어 의뢰를 받고 무법자를 처치하는 3D 액션 게임 (Unity · URP, 2023).

## 영상

[![플레이 영상](https://img.youtube.com/vi/473K7-S3Ueo/hqdefault.jpg)](https://youtu.be/473K7-S3Ueo)

## 마을

| NPC | 역할 |
|---|---|
| 바텐더 | 의뢰(퀘스트) 발급 · 진행 상태 확인 |
| 마차 | 의뢰 지역으로 이동 |
| 무기상 | 권총 · 산탄총의 공격력 · 공격 속도 강화 |
| 상인 | 체력 · 방어력 강화 |
| 이발사 | 캐릭터 스타일 · 색 변경 |
| 딜러 (게임 테이블) | 미니게임 **블랙잭** — 배팅 · 히트 · 스테이 |
| 장의사 | 쓰러지면 이곳에서 부활 |
| 수녀 · 도박꾼 | 대화 |

## 전투

- 권총 · 산탄총
- 의뢰 지역의 적을 모두 처치하면 의뢰 완료, 보상으로 돈을 받아 강화
- 적 AI는 행동 가중치에 따라 이동 · 공격
